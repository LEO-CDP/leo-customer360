Web SDK Event Catalog Reference

        
Comprehensive specification of standard events captured by the LeoCDP Web SDK.


        

          

            
1. View Events

            
    
              
  • page-view: Triggered on initial document load with marketing UTM parameters.
    • 
              
  • content-view: Article, blog post, or knowledge base read engagement.
    • 
              
  • item-view: E-commerce product catalog or SKU detail display.
    • 
              
  • login-success: Successful authentication screen display.
    • 
            

          


          

            
2. Action & Interaction Events

            
    
              
  • click-details: Generic button, link, or tab click interaction.
    • 
              
  • search: Internal site search queries, filters, and result counts.
    • 
              
  • submit-contact: Contact form or lead generation submission.
    • 
              
  • register-account: New user account registration.
    • 
              
  • user-login & logout: Authentication session state changes.
    • 
              
  • ask-question: Conversational AI query or support bot interaction.
    • 
            

          


          

            
3. Conversion & E-Commerce

            
    
              
  • purchase / checkout: Complete order conversion with monetary value, tax, currency, and line items.
    • 
              
  • add-to-cart: Shopping cart additions for abandoned cart tracking.
    • 
              
  • short-link-click: Inbound campaign link attribution.
    • 
            

          


          

            
4. Identity & Personalization

            
    
              
  • profile-update: Customer identity linkage (email, phone, name, CRM ID) for CIR.
    • 
              
  • submit-survey / submit-nps: Customer sentiment and feedback scoring.
    • 
              
  • getPersonalization: Slot-based dynamic content recommendations.
    •
