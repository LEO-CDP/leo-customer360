# System users page

This page lists the staff accounts that can sign in to this workspace. It is opened from the Admin tab in the top navigation. Each row is one staff user; the Edit modal is where you view and change it.

## What you can do here
- **Search**: "Search username, email, name…" filters the list as you type.
- **Filter by status**: All status, Active, Inactive.
- **Add System User**: opens the create form.
- **Read the table**: User (full name and username), Email, Job Title, Department, Status and Last Login.
- **Edit a user**: use the Edit action; rows do not open a detail page.

### The add/edit form
- **Fields**: Username, Full Name, Email, Phone, Job Title, Department, Password, Confirm Password and Status.
- **Password**: required when creating a user (at least 8 characters, entered twice); it is not shown when editing.
- **Status options**: Active, Inactive.
- **Save**: Save User for a new user or Save Changes when editing; Cancel closes. Deactivate is available when editing. The Username cannot be changed after creation.

## Common questions
- **How do I add a staff user?** Add System User, set a username and password, then save.
- **How do I remove someone's access?** Open the user with Edit and press Deactivate.
- **Why can't I change a username?** It is fixed once the user is created.
- **Where do I see when someone last signed in?** The Last Login column.
- **Can I reset a password here?** No; the password is only set when creating a user.
