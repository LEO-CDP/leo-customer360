# Master profiles page

This page lists every master customer profile in the tenant — the unified records built by identity resolution from raw and domain profiles. It is the Profiles tab, and it is where you start when you need to find one customer. Selecting a row opens that customer's profile page.

## What you can do here
- **Search**: the search box ("Search name, persona, email, phone...") filters as you type; the clear button resets it.
- **Filter by date**: From and To filter by last activity or profile update date.
- **Filter by profile scope**: Domain (All domains), Data source (All data sources) and Linked raw profiles (Minimum count).
- **Filter by identity signal**: Anonymous ID and Device fingerprint.
- **Filter by customer segmentation**: Lifecycle (All lifecycle stages, Prospect, Lead, Customer, VIP, Dormant, Churn risk), Value tier (All value tiers, Low Value, Medium Value, High Value) and Churn risk (All churn risks, Low Risk, Medium Risk, High Risk, Critical Risk).
- **Read the table**: Profile, Domain, Tier, Lifecycle, Churn Risk, Linked Profiles, Total Events and Last Activity / Update.
- **Open a customer**: click any row to go to the customer profile page.
- **Page through results**: Previous, Next and the page label; the footer shows "Showing X-Y of N profiles".

## Sections of the page
- **Header and filters**: the search box and the Date range, Profile scope, Identity signals and Customer segmentation filter groups.
- **Profiles table**: the list of matching master profiles.
- **Footer**: the result count and pagination. If nothing matches, the table shows "No profiles matched your filters" with a Clear search link.

## Common questions
- **How do I find one customer?** Type a name, persona, email or phone in the search box.
- **What does "Linked Profiles" mean?** The number of raw records that identity resolution merged into this master profile.
- **Why does a profile show a generic name?** When the domain hides real names, the row falls back to the persona name or a short profile label.
- **How do I narrow to VIPs or at-risk customers?** Use the Lifecycle, Value tier and Churn risk filters.
- **Where do I see everything about a customer?** Click the row to open the customer profile page.
